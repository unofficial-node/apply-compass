# 2027학년도 대학·학과 데이터 검수

## 기준

- 대상 입학 시점: 2027년 3월
- 기준 학년도: 2027학년도 대학입학전형
- 우선 근거: 각 대학 입학처의 2027학년도 시행계획 및 최종 모집요강
- 공식 자료로 모집단위를 확정할 수 없는 항목은 임의로 보완하지 않고 `공식 확인 필요`로 유지
