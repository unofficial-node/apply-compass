# 2027학년도 대학·학과 데이터 검증

## 기준

- 대상 입학 시점: 2027년 3월
- 기준 학년도: 2027학년도 대학입학전형
- 대상 학교: 4년제 대학 및 별도 학사과정 대학
- 제외 학교: 전문대학 및 2년제 과정
- 우선 근거: 각 대학 입학처의 2027학년도 최종 모집요강
- 보조 근거: 최종 모집요강이 아직 없을 때 각 대학 입학처의 2027학년도 대학입학전형 시행계획
- 공식 자료만으로 모집단위를 확정할 수 없는 항목은 임의로 보완하지 않고 `공식 확인 필요`로 유지한다.
